## The economic case

| Item | Cost as % of revenue |
|---|---|
| Planned maintenance (labour + parts) | 3–5% |
| Unplanned downtime | 8–15% |
| Emergency parts premium | 1–2% |
| Quality losses from degraded equipment | 2–4% |

A mill that spends 3% on planned maintenance spends 8% or less in total. A mill that spends 1% spends 15% or more. This is one of the few places in milling where the cheaper option is reliably the more expensive one.

## The failure modes you are managing

| Component | Dominant failure mode | Warning signal | Prevention |
|---|---|---|---|
| Roll mill bearings | Fatigue, contamination | Temperature rise 8–15 °C, vibration | Lubrication, seals |
| Roll flutes | Wear | Falling extraction, rising ash | Depth measurement |
| Sifter screens | Blinding, tearing | Reduced sifting, tailings rise | Inspection, cleaning |
| Sifter hangers | Rubber fatigue | Vibration, noise | Replacement on schedule |
| Bucket elevator belt | Stretch, splice failure | Belt slip, misalignment | Tension, splice inspection |
| Conveyor bearings | Seizure | Temperature, noise | Lubrication |
| Rotary valves | Seal wear | Air leakage, capacity loss | Seal replacement |
| Filter bags | Blinding, rupture | Differential pressure | DP monitoring |
| Motors | Winding failure, bearing | Current imbalance, temperature | Thermography, lubrication |
| Pneumatic lines | Wear at bends | Capacity loss, leakage | Bend inspection |

## Daily (operator, every shift)

| Task | Check | Record |
|---|---|---|
| Bearing temperatures | All roll mills, sifters, elevators — touch or IR gun | Any above 70 °C flagged |
| Abnormal noise | Walk the plant, listen | Reported |
| Vibration | Hand on housing, feel | Reported |
| Belt tracking | Visual on all conveyors | Adjusted if off |
| Spouting leaks | Visual | Sealed |
| Dust emission | Visual at transfer points | Reported |
| Sifter sound | Normal rhythm vs labouring | Reported |
| Bin levels | All bins | Confirmed |
| Compressed air pressure | Gauge | Logged |
| Finished flour appearance | Colour, feel | Logged |

Fifteen to twenty minutes per shift. It catches most failures days before they stop production.

## Weekly

| Task | Standard |
|---|---|
| Lubrication — roll mill bearings | Grease per manufacturer spec, not "a bit" |
| Lubrication — sifter drive | Oil level, top up |
| Roll gap check | Feeler gauge on 3 passages minimum, rotating |
| Filter differential pressure | Record; clean or replace above 1,500 Pa |
| V-belt tension | Deflection test |
| Screens visual | Look for blinding, tears, slack |
| Magnetic separators | Clean magnets, inspect for metal |
| Compressed air traps | Drain |
| Electrical panel temperature | IR scan or hand check |
| Spouting and flexible connections | Tighten, replace worn |

## Monthly

| Task | Standard |
|---|---|
| Roll condition inspection | Magnification on 2 passages |
| Flute depth measurement | Every passage, quarterly rotation |
| Sifter screen full inspection | Light behind screen, all sections |
| Sifter hanger inspection | Cracks, rubber degradation |
| Bearing vibration measurement | Overall velocity, all critical bearings |
| Motor current measurement | Compare against baseline |
| Gearbox oil sampling | Visual + water check |
| Structural bolt torque | Roll mill bases, sifter frames |
| Explosion vent inspection | Intact, unobstructed |
| Bonding and grounding check | Continuity on all equipment |
| Housekeeping audit | 0.8 mm threshold, documented |

## Quarterly

| Task | Standard |
|---|---|
| Full roll flute depth survey | All 11 passages, trended |
| Bearing greasing schedule review | Adjust based on temperature trend |
| Electrical thermography | All panels under load |
| Purifier brush condition | Replace worn |
| Bran finisher screen condition | Replace if holed |
| Packing machine calibration | Weight accuracy ±0.5% |
| Safety device testing | Interlocks, emergency stops |
| Spare parts stocktake | Reconcile against minimums |
| Vibration trend analysis | Identify bearings trending up |

## Annual

| Task | Standard |
|---|---|
| Full plant overhaul | Planned shutdown, 3–7 days |
| Roll re-fluting assessment | All rolls, re-flute as needed |
| All bearings inspected | Replace any showing wear |
| Sifter hangers replaced | On 2–3 year cycle |
| Alignment check | All drives, laser alignment |
| Gearbox oil change | Full drain and refill |
| Electrical insulation testing | All motors above 15 kW |
| Filter bags replaced | Full set |
| Structural inspection | Cracks, corrosion, bolt tension |
| Dust hazard analysis review | update for changes |
| Pressure vessel inspection | Where applicable, statutory |
| Calibration of all instruments | Against certified standards |

## Condition monitoring: the multiplier

Preventive maintenance is calendar-based. Condition monitoring is state-based, and it finds the failures that calendars miss.

| Technique | Detects | Cost | Interval |
|---|---|---|---|
| Vibration (overall) | Bearing wear, imbalance, misalignment | USD 300 tool | Monthly |
| Vibration (spectrum) | Specific bearing defect frequencies | USD 3,000–15,000 | Quarterly |
| Thermography | Electrical hotspots, bearing heat | USD 1,500–8,000 | Quarterly |
| Oil analysis | Wear metals, water, viscosity | USD 30–60/sample | Quarterly |
| Motor current signature | Rotor bars, eccentricity | USD 5,000+ | Annually |
| Ultrasonic | Early bearing, air leaks | USD 500–2,000 | Monthly |

For a 200 t/d plant, a vibration pen, an IR camera and quarterly oil sampling cost under USD 15,000 and typically prevent two to four failures a year at USD 15,600 per day. It is the highest-return maintenance investment available.

### Bearing temperature thresholds

| Temperature | Action |
|---|---|
| Below 60 °C | Normal |
| 60–70 °C | Monitor daily |
| 70–80 °C | Investigate: lubrication, alignment, load |
| 80–90 °C | Plan replacement within days |
| Above 90 °C | Stop and replace |

A bearing does not go from 55 °C to failure in an hour. It goes 55 → 62 → 70 → 78 over weeks. The temperature log is the early warning system, and it only works if someone reads it.

## Records that make it work

| Record | Purpose |
|---|---|
| Daily checklist with signature | Accountability |
| Lubrication log per point | Prevents double-greasing and missed points |
| Bearing temperature trend | Predicts failure |
| Roll gap log | Correlates with flour quality |
| Flute depth history | Justifies re-fluting spend |
| Vibration trend | Predicts bearing replacement |
| Breakdown log with root cause | Prevents repeat failures |
| Spares consumption | Sets stock levels |

A maintenance system without records is a set of good intentions. The signature is what converts it into a programme.

## Staffing

| Plant | Maintenance staff |
|---|---|
| 20 t/d | 1 shared with production |
| 60 t/d | 1 dedicated |
| 200 t/d | 3–4 (mechanical 2, electrical 1, instrument 1) |
| 500 t/d | 6–9 |

The ratio that matters: **one maintenance technician per 40–60 t/d of capacity** for a plant running 24/5. Below that, preventive tasks get deferred during busy periods, which is exactly when they matter most.

## The shutdown discipline

An annual overhaul only saves money if it is planned.

| Requirement | Why |
|---|---|
| Fixed date, 12 months ahead | Allows spares to be ordered at normal price |
| Full parts list confirmed 8 weeks prior | Avoids expedited freight |
| All rolls assessed before shutdown | Re-fluting planned, not discovered |
| Production builds buffer stock | Avoids customer shortfall |
| Contractors booked | Avoids queueing |
| Written scope per area | Avoids "while we are in there" scope creep |

A well-run 200 t/d plant completes a full overhaul in 5 days. The same work done as unplanned breakdowns takes 12–18 days spread across the year, and produces worse results.
